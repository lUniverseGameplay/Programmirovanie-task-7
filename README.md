Программирование, 7 задача, 2 курс, 1 семестр.

Приложение с графическим интерфейсом для сортировки списка студентов на кафедре. В приложении реализованы следующие сортировки: метод прямого выбора, прямого обмена, прямого включения, шейкерная, метод Шелла.

<img width="987" height="696" alt="image" src="https://github.com/user-attachments/assets/d9d3eb89-44bd-464c-87aa-8c4542abc34d" />

Интерфейс демонстрирует список студентов (ФИО, специальность, группа), отсортированный список студентов, а также время затраченные на сортировку и количество перестановок.
